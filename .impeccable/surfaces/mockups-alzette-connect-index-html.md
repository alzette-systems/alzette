# Alzette Connect launcher mockup

- **Mode:** Operate.
- **Audience/job:** An entitled employee launches a familiar qualified AI application through Alzette without handling a reusable remote credential.
- **Primary task:** Confirm the current company context and synchronized model catalogue, then double-click or keyboard-launch an installed application. Catalogue-capable adapters receive all compatible assigned models; single-model adapters ask once at launch.
- **Truth constraints:** This is an illustrative platform-neutral mockup. Installed is not Ready without adapter/version/protocol/policy evidence. No production desktop artifact or Claude/Codex support is claimed.
- **Direction:** Compact app-first launch ledger in the existing Scoped Ledger world. The memorable moment is that each application row states both support readiness and exactly how many models it will receive.
- **Lifecycle:** Signed out, launcher, preparing, running, and recovery are states of one window. Running applications remain visible in the launcher and Connect may move to the tray.
- **Open decisions:** First signed OS, desktop bundle technology, exact client configuration APIs, multiple concurrent sessions, and the production model catalogue.
